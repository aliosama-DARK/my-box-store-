# MY BOX STORE — Printing & Gifts 🛍️

متجر طباعة وهدايا مخصصة (عربي RTL) مع لوحة تحكم إدارية كاملة لإدارة المنتجات والطلبات والعروض.

## المميزات

- 🛒 **متجر كامل**: منتجات، سلة، إتمام طلب من الموقع مباشرة
- 📊 **لوحة تحكم إدارية** على `/admin`:
  - نظرة عامة (إحصائيات الطلبات والمنتجات)
  - إدارة الطلبات: 8 حالات، بحث وفلترة، تواصل واتساب مع العميل
  - إدارة المنتجات: إضافة/تعديل/إخفاء/حذف، رفع صور، عروض بتواريخ، مخزون يُخصم تلقائياً
  - إعدادات: تفعيل/إيقاف الطلب عبر واتساب، مصاريف الشحن
- 🔐 **أمان**: تسجيل دخول بجلسات، تشفير كلمة السر scrypt، حساب الأسعار من قاعدة البيانات، honeypot وrate limiting

## التقنيات

Node.js (بدون أي مكتبات خارجية — `node:sqlite` المدمج) + HTML/CSS/JS خالص.

## التشغيل

يتطلب Node.js 22.5 أو أحدث.

```bash
node server.js
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

**تغيير كلمة سر الأدمن (مهم قبل النشر):**

```bash
node server.js --set-password كلمة_سر_جديدة
```

## النشر

الموقع يحتاج استضافة تدعم Node.js (مثل Railway أو Render أو VPS). ملاحظة: GitHub Pages لا يكفي لأنه يستضيف ملفات ثابتة فقط بدون سيرفر أو قاعدة بيانات.

قاعدة البيانات تُنشأ تلقائياً في `data/store.db` عند أول تشغيل (غير مرفوعة في المستودع).
